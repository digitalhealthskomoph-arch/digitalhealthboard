# Digital Health Board (ระบบจัดการสำหรับคณะกรรมการสุขภาพดิจิทัล)

## คุณสมบัติหลัก (Features)
- แผงควบคุมภาพรวม (Dashboard)
- ระบบจัดการแผนยุทธศาสตร์และตัวชี้วัด (Strategic & KPIs)
- ระบบจัดการวาระการประชุม (E-Meeting)
- ระบบข้อมูลรายชื่อคณะกรรมการ (Board Members)
- ศูนย์รวมแหล่งข้อมูลและลิงก์ (Resources)

## เทคโนโลยี (Tech Stack)
- **Frontend:** Next.js (App Router), Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **Deployment:** Netlify
